# 🌊 Windy | Öğrenmenin Okyanusu ☁️

**Windy**, öğrenmeyi eğlenceli ve keşfetmeyi heyecanlı hâle getirmek için tasarlanan kişisel bir öğrenme platformudur.

## 🐠 Özellikler

* 🌊 Okyanus temalı mavi tasarım
* ☁️ Wind adlı sevimli bulut rehberi
* 🔬 Bilim, matematik, uzay, doğa ve diğer konularda keşif
* 👤 Kişisel profil oluşturma
* 💡 İlgi alanlarına göre öğrenme
* ✨ Eğlenceli bilgilerle yeni şeyler keşfetme

## 🎯 Amacımız

Windy'nin amacı, öğrenmeyi yalnızca ders çalışmaktan ibaret olmaktan çıkarıp eğlenceli bir keşif yolculuğuna dönüştürmektir.

## 🛠️ Kullanılan Teknolojiler

* HTML
* CSS
* JavaScript

## 🚀 Projeyi Görüntüle

Windy web sitesini GitHub Pages üzerinden yayınlamayı hedefliyoruz.

## 💙 Windy Dünyasına Hoş Geldin!

**Her gün yeni bir şey öğren, okyanusun derinliklerini keşfet!** 🌊🐬
